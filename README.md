# Marketing Funnel & Conversion Analysis

## 📊 Project Overview
This project analyzes marketing funnel data to understand user conversion from visitors to customers.

## 🛠 Tools Used
- Power BI
- Excel / CSV Dataset

## 📈 Key Insights
- High drop-off in conversion stage
- Some channels perform better than others
- Conversion rate is low

## 💡 Recommendations
- Improve lead follow-up
- Focus on high-performing channels
- Retarget potential customers

- Power BI Dashboard (.pbix)
- Dataset
